# Rule changes

What changed in the rules agents work under in this repo, newest last. One line per merged change to a gate file (list: "Approval and shipping" in `docs/guidelines/repo-standards.md`), written by the agent and checked by the gate-change reviewers. Append only — `agent-approval.sh` refuses a branch that edits or removes a line. Merged PRs carry the `rules-changed` label. Disagree with one? Revert that PR.

Format (indented here so it is not itself an entry):

    - YYYY-MM-DD #<issue> — <what the rules now do differently, and why>

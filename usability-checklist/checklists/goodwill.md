# Goodwill

**Principle:** every user arrives with a reservoir of goodwill. Each annoyance drains it and each kindness refills it. When it runs out, they leave, and they may not come back.

## Things that drain it

| ID | Check | How to check |
|---|---|---|
| G1 | Information users want is not hidden | Prices, shipping costs, phone number and support contact are easy to find |
| G2 | Users are not punished for doing it their way | No rigid formats for phone, date or card number. See F4 |
| G3 | No information is asked for that is not needed | Every personal question has a visible reason |
| G4 | No fake sincerity | No "your call is important to us" while making the user wait |
| G5 | No marketing in the user's way | No splash screen, interstitial, forced signup or newsletter popup before the user gets value |
| G6 | The site looks cared for | No broken images, dead links, stale dates, layout glitches or leftover template text |

## Things that refill it

| ID | Check | How to check |
|---|---|---|
| G7 | The things most users come for are obvious and easy | Name the top three tasks. Each is reachable from the first screen |
| G8 | Costs and catches are stated up front | Full price, fees and limits are shown before the user commits, not at the last step |
| G9 | Steps are saved wherever possible | Prefilled fields, remembered choices, a tracking link in the email rather than a number to copy |
| G10 | The likely questions are answered | The FAQ holds the questions users really ask, with straight answers, kept current |
| G11 | Recovery from errors is easy | Messages say what happened and what to do. Nothing typed is lost. See F8 and F9 |
| G12 | Comforts are provided | Printer-friendly pages, a saved cart, an order summary, a confirmation email |
| G13 | When something cannot be done, the site says so and apologises | An honest "we can't do X yet" beats silence |

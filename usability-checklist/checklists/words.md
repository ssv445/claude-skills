# Words

**Principle:** most words on most pages are never read. Remove half, then remove half of what is left. Fewer words make the useful ones visible.

| ID | Check | How to check |
|---|---|---|
| W1 | No happy talk | Welcome text and self-congratulation that carry no information. Test: while reading it, do you hear "blah blah blah"? Delete it |
| W2 | Instructions are cut to the minimum | Nobody reads them. First make the step obvious, then delete the instruction. Keep only what is truly needed |
| W3 | Each paragraph earns its place | For each one: would a user miss it if it were gone? |
| W4 | The page is about half the length it could be | Try cutting half the words. Did any meaning go? |
| W5 | Plain words, no jargon | No "synergy", "solutions", "best-in-breed", "leverage". No internal terms |
| W6 | The important sentence comes first | Each section leads with its point, not a wind-up |
| W7 | Text is specific | Numbers, names and facts, not adjectives. "Ships in 2 days", not "lightning-fast delivery" |
| W8 | Link and button text stands on its own | It makes sense read out of context, as a scanning user reads it |

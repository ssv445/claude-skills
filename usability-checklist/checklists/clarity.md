# Clarity

**Principle:** a page should be self-evident. A first-time user should know what it is and what to do without stopping to work it out.

| ID | Check | How to check |
|---|---|---|
| C1 | A first-time visitor can say what this page is for within 5 seconds | Look at the top of the page only. Is the purpose stated in plain words? |
| C2 | The next step is obvious | One action stands out as the thing to do here |
| C3 | Labels use the user's words | No internal, clever or marketing names: "Jobs", not "Career Hub"; "Pricing", not "Plans & Possibilities" |
| C4 | Nothing important depends on reading instructions | Remove the instructions in your head. Can the page still be used? |
| C5 | Each name means one thing | The same thing is not called "account", "profile" and "workspace" in different places |
| C6 | Nothing makes the user ask "where am I?", "where do I start?", "why did they call it that?" or "is that clickable?" | List each such question the page raises. Each one is a failure |
| C7 | When a thing cannot be made self-evident, it is self-explanatory | A short phrase next to it settles the question. New or unusual features get this |
| C8 | The page looks like what it is | A signup page looks like signup, a product page looks like a product page. No surprises in type |
